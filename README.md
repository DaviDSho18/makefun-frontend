A fast, static make.fun frontend: a bounty board, a bounty page, a leaderboard and a profile, each on its own hash route, reading make.fun's public API with no build step and no dependencies.

## Run it

```sh
node serve.ts          # serves app/ on http://localhost:8080 (--port for another)
```
